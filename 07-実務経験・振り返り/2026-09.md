### 2026-09-01：業務設計・サービス設計の配置ルールが不明確


| 観点      | 内容                                                                                                                          |
| ------- | --------------------------------------------------------------------------------------------------------------------------- |
| 起きたこと   | 業務設計とサービス設計の各カテゴリに、どのようなドキュメントを配置すべきか判断できなかった                                                                              |
| 問題・影響   | 作成すべきドキュメントとカテゴリの境界が決まっていないため、メンバーごとに成果物の内容や配置場所が異なる。他のカテゴリに属するドキュメントが混在すると、必要な情報を見つけにくくなり、内容の理解や確認、更新に時間がかかる |
| 原因      | 業務設計とサービス設計それぞれの目的、扱う情報、配置対象、対象外となるドキュメントをあらかじめルールとして定め、チームに共有していなかった                                         |
| 改善策     | 各カテゴリの目的と責務を明確にし、配置するドキュメントの種類、記載内容、配置基準、対象外となる例をルールとして定める。判断に迷うケースも具体例として示し、メンバーが同じ基準で分類できるようにする                    |
| 次のアクション | 現在の業務設計とサービス設計のドキュメントを一覧化し、それぞれの目的と内容を確認する。その結果を基に配置基準の案を作成してチームで合意し、既存ドキュメントの配置を見直す                          |


#### 論理の流れ

配置ルールがない → 各カテゴリの目的と境界を判断できない → メンバーごとに成果物の内容や配置場所が異なる → 他のカテゴリのドキュメントが混在する → 必要な情報を見つけにくくなり、理解・確認・更新に時間がかかる

### 2026-09-10：ドキュメントの情報過多と重複


| 観点      | 内容                                                                                                                     |
| ------- | ---------------------------------------------------------------------------------------------------------------------- |
| 起きたこと   | ドキュメントを読み込むのに時間がかかり、読み進める意欲も低下した                                                                                     |
| 問題・影響   | 情報の重要度を判別しにくいため、レビュー時の確認負荷が高まり、重要な記述を見落とす可能性がある。また、同じ内容が複数の場所に記載されると更新漏れによる差異が生じ、どの情報が正しいか判断できない状態が蓄積する |
| 原因      | 1ファイルあたりの情報量が多く、ドキュメントで最も伝えたいことが明確になっていなかった。そのため、読み手はすべての情報を同じ注意力で確認する必要があった。また、重複する情報の正本を決めていなかった           |
| 改善策     | 1つのドキュメントで伝える主要な目的を1つに絞り、その目的に必要な情報だけを記載する。別の目的に属する情報は適切なドキュメントへ分け、重複する内容は正本を1か所に定めて参照リンクだけを記載する               |
| 次のアクション | 作成前に、そのドキュメントで誰に何を伝えるかを1文で定義する。目的に関係しない情報は削除するか適切なドキュメントへ移動する。重複する内容は正本を確認し、それ以外の記載を参照リンクへ置き換える             |


#### 論理の流れ

- 1ファイルの情報量が多い → 伝えたいことと情報の重要度を判別しにくい → すべてを同じ注意力で確認する必要がある → レビュー負荷が高まる → 重要な記述を見落とす
- 同じ情報が複数の場所にある → 更新対象が増える → 更新漏れによる差異が生じる → どの情報が正しいか判断できなくなる → 信頼できない情報が蓄積する
