# 基盤・インフラ

## 概要

ネットワーク、クラウド、コンテナなど、システムを動かす基盤技術のリファレンスを整理しています。

このカテゴリでは、アプリケーションが利用する土台の動作原理と、アプリケーションを実行・公開する環境を扱います。

---

## 目次

| カテゴリ | 内容 |
|---------|------|
| [AWS](./aws/) | AWSインフラ学習ロードマップ |
| [Docker](./docker/) | Dockerの基礎（コンテナ・イメージ・Compose） |
| [Networking](./networking/) | HTTP通信、ネットワーク基礎、Web公開の基礎知識 |

---

## 分類の境界

| 内容 | 配置先 |
| --- | --- |
| HTTP、Cookie、ネットワークなどの動作原理 | `05-基盤・インフラ/` |
| AWS、Docker、ホスティングなどの実行基盤 | `05-基盤・インフラ/` |
| APIやアーキテクチャの構造を決める知識 | `03-設計/` |
| CI/CD、IaC、GitOps、可観測性などの運用自動化 | `06-DevOps/` |
| 認証・認可、暗号、攻撃対策などの保護設計 | `08-セキュリティ/` |
| Gitやyt-dlpなど、単独で利用するツール | `09-ツール/` |

同じ技術でも、説明する関心事によって分類します。たとえば、Cookieの保存・送信仕様はこのカテゴリ、Cookieを使った認証方式や攻撃対策は `08-セキュリティ/`、Next.js固有のCookie APIは `02-フレームワーク/` に配置します。
